Write $\tau_t = \theta_t - \theta_0$ for the delta a fine-tune produced. Task
arithmetic observes that $\theta_0 + \sum_t \lambda_t \tau_t$ often behaves like a
model trained on the union of those tasks, and that negating a $\tau$ subtracts the
behaviour. TIES and DARE add conflict resolution: trim small entries, elect a sign
per coordinate, and average only the agreeing deltas.

The reason this is a stub is that the explanation is not settled. Linear mode
connectivity between fine-tunes of a shared base is the usual account, but it is a
description of when merging works rather than a prediction, and the failure cases
have not been rederived here.
