Because the residual stream is a sum, a component's output reaches every later
block. Patching it measures the total effect along all paths simultaneously. To
isolate an edge $A \rightarrow B$ you must present the patched value of $A$ to $B$
alone, while every other consumer of $A$ continues to see the original.

<Eq caption="eq. 1 — one edge, all other consumers untouched" lead>

$$
\mathrm{effect}(A \rightarrow B) =
M\bigl( \mathrm{do}(\mathrm{input}_B(A) \leftarrow a') \bigr) - M(\cdot)
$$

</Eq>

<Note label="caveat">
Direct-effect-only patching — freezing every intermediate rather than recomputing —
answers a third question again. The three variants are routinely conflated. State
which one you ran.
</Note>

Implementation requires three runs: a clean run, a corrupt run, and a run in which
$B$ is recomputed from a residual stream that has had $A$'s contribution swapped,
with everything downstream of $B$ then freely recomputed. Doing it for all pairs is
quadratic in components, which is why
[attribution methods](/entries/attribution-patching) exist.
